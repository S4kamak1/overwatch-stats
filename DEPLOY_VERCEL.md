# Deploy cloud ingest

Import this repository into Vercel:

https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FS4kamak1%2Foverwatch-stats&repository-name=overwatch-stats-ingest

After deployment, verify:

`https://<project>.vercel.app/api/health`

The response should contain `ok: true`.
